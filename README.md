# Language Exercises

The same set of beginner Python exercises, reimplemented in **Go**, **Rust** and **C++**.

I used this to learn each language's fundamentals by solving problems I already understood, so I could focus on syntax, idioms and how each language handles things like types, memory and error handling.

## Structure

| Folder | Language |
|--------|----------|
| `go/`   | Go   |
| `rust/` | Rust |
| `cpp/`  | C++  |

## Contents

Each folder contains the exercises from the first Python module (Python 00) of the 42 Common Core.

## Running

- **Go:** `go run <file>.go`
- **Rust:** `rustc <file>.rs && ./<file>`
- **C++:** `c++ <file>.cpp -o <file> && ./<file>`
